Detailed Description

Options used when loading a mesh or a scene.

Note that not all options are supported for all backends or filetypes.

Member Data Documentation

◆ stitch_vertices

bool stitch_vertices = false

Stitch duplicate boundary vertices together when loading file.

When loading a glTF mesh with attributes, or when loading STL files, the loader will warn the users about unwelded vertices in the loaded mesh, unless silenced by setting quiet to true.
